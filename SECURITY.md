# Security policy

Report suspected security vulnerabilities privately. Do not open a public issue or pull request containing vulnerability details, exploit steps, credentials, private artwork URLs, or personal data.

## Reporting

Use GitHub private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner or a maintainer privately using a contact method listed on their GitHub profile.

Include the affected version, browser and operating system, the impact you observed, and clear reproduction steps. Remove credentials, session tokens, and personal information from logs or screenshots.

The maintainers will review reports and coordinate any fix or disclosure with the reporter. The project does not promise a response or resolution timeframe.
