Changelog

What changed, version by version.

New features, changes, and fixes in each release of Deviation Lens, newest first. Found a problem? Report it on GitHub.

0.2.1

November 2026

Fixed

  • After you open another artwork from a DeviantArt page, the side panel now lists that artwork. It used to keep showing the previous one under the new title.
  • Previews of paid artwork, such as adoptables, are now found. The side panel used to list a different image from the page instead.
  • After the extension updates, the side panel can scan DeviantArt tabs that were already open, without refreshing them.

0.2.0

November 2026

Added

  • Saving two or more images now creates one ZIP file. This covers Download all, Download selected, and profile date ranges.
  • Each ZIP includes a manifest.csv listing the artist, title, date, source page, and size of every file.
  • A ZIP keeps building if you close the side panel, and you can cancel it while it runs.
  • If some images can’t be added to a ZIP, the rest are still saved, and you can retry the others as separate files.
  • A settings page, opened from the new gear icon, with every option in one place.
  • Your first download now asks where files should go: a folder you choose, a Save As dialog each time, or your Downloads folder.
  • A minimum image size filter: HD, Full HD, QHD, or 4K and larger.
  • File name templates such as {artist}/{date}_{title}, which can also create folders.
  • An optional history that marks artwork you already saved and skips it in bulk downloads. It is off by default and stays in your browser.
  • This changelog.

Changed

  • The gear icon replaces the Folder button in the side panel.
  • Best only, Small variants, Include Explore sections, and Find images on any page moved from the side panel to the settings page.
  • The side panel shows a note when a filter is hiding images.
  • “Ask every time” now opens one Save As dialog per ZIP instead of one per image.
  • Fewer permissions: the activeTab permission is gone, built-in site access is HTTPS only, and DeviantArt pages can no longer read any of the extension’s files. A new offscreen permission builds ZIP files, with no new install warning expected.
  • Removed an unused sidebar experiment from the package.
  • Version numbers are now plain, such as 0.2.0, without an alpha label. Deviation Lens is still in early access until 1.0.

Fixed

  • Saving to a custom folder no longer overwrites an existing file with the same name.
  • If Chrome drops access to your custom folder, downloading now asks for access again instead of failing.
  • Very long file names keep their extension when shortened.
  • Files can no longer take a name that Windows reserves, such as CON or NUL.

0.1.0-alpha.1

October 2026

Added

  • First public alpha.
  • Scan DeviantArt pages for supported images and their available variants.
  • Compare image dimensions, estimated file sizes, and quality details in the side panel.
  • Exclude Explore sections by default, with a saved option to include them.
  • Scan other websites after enabling Find images on any page and granting Chrome access.
  • Download the best version, your selected images, or all results, or copy image URLs.
  • Download a profile’s artwork by date range.
  • Choose where downloads are saved.
