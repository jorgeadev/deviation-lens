# Support

For usage questions, first check the repository README and search existing GitHub issues. If you do not find an answer, open an issue with the question and the relevant extension version and browser.

Use the bug report template for reproducible defects and the feature request template for proposed behavior. Do not include passwords, session tokens, private messages, or other sensitive information.

Support for DeviantArt accounts, moderation, billing, or site availability is outside this project. Contact DeviantArt for those issues.
